## Product and content guardrails

- Kemma is a product and software engineering company based in Accra and
  working with organisations anywhere. Geography is context, not a limit.
- Do not fabricate clients, projects, metrics, testimonials, team members,
  partnerships, awards or production status.
- Keep unverified outcomes framed as implementation capabilities. Add a live
  URL, screenshot or business result only after it has been verified.
- Use the canonical production host `https://www.kemmatechnologies.com`; the
  apex currently redirects to `www`.
- Use `pageMetadata()` from `lib/seo.ts` for page metadata and the builders in
  that module for structured data.
- Preserve the no-JavaScript contract: server-rendered content must never
  depend on client hydration to become visible.

## Current engineering state

- Next.js 16.2.12, React 19.2.4, strict TypeScript and Tailwind CSS v4.
- MDX frontmatter is parsed as YAML and validated with Zod. Invalid projects
  are skipped with a warning instead of crashing the site.
- The contact route accepts JSON only, limits requests to 16 KiB, rejects
  unknown or oversized fields, escapes email HTML, and retains the honeypot.
- Production email configuration fails visibly instead of pretending an
  enquiry was delivered.
- The default social preview is generated by `app/opengraph-image.tsx` at
  1200×630 and is inherited by pages without a project-specific image.
- CI installs from the lockfile, audits dependencies, and runs the complete
  verification gate on Node.js 24.

## External checks before calling the release complete

These require account access or a business decision and cannot be proven by a
local build:

1. Confirm `NEXT_PUBLIC_SITE_URL=https://www.kemmatechnologies.com` in every
   production Vercel environment that can override the code fallback.
2. Confirm `RESEND_API_KEY` and `CONTACT_FROM_EMAIL` are configured, the sender
   domain is verified, and run one controlled enquiry-delivery test.
3. Follow `docs/vercel-firewall.md`: create the contact-route rate-limit rule
   in log mode, review legitimate traffic, then have an authorised owner
   publish enforcement. Do not silently publish a production firewall rule.
4. Supply Constract's verified live URL before restoring any claim about real
   customer orders or production usage.
5. Add only real, approved project imagery and outcomes as they become
   available.

## Intentionally deferred

- A strict nonce-based CSP was not added. In Next.js it makes otherwise static
  pages dynamic; choose this only after weighing that deployment trade-off.
- WebGL changes beyond the existing reduced-motion and device-pixel-ratio
  controls should be driven by measured performance data.
- A full responsive-device and Lighthouse sweep belongs to the preview
  deployment, where fonts, image optimisation and third-party behavior match
  production.
